Manual de marca

01 · Introducción

Visión general del template

Template marca blanca para Objetos Virtuales de Aprendizaje (OVA). Una sola base, muchos cursos.

Este template se diseñó para que el equipo académico pueda producir cursos con apariencia consistente y profesional sin necesidad de tocar CSS. Solo varían: paleta de colores, logo y contenido.

El sistema en una frase

El curso define 2 colores (acento + info) y elige 1 de 3 versiones (Híbrida, Clara, Oscura). Con eso el template completo se pinta automáticamente.

02 · Color

Sistema de color

Solo 2 variables CSS definen toda la marca del curso.

Las 2 variables base

/* assets/css/theme.css */
:root {
  --c-acento: #F37021;  /* botones, énfasis, gradientes */
  --c-info:   #38E1FF;  /* chips, eyebrows, datos */
}

Lo que se deriva automáticamente

TokenFórmulaUso
--acento-soft--c-acento × 12%Fondos sutiles
--acento-deep--c-acento × 70% + blackFinal del gradient
--acento-light--c-acento × 50% + whiteTexto en sidebar dark
--grad-brandlinear-gradient(acento → deep)Botones primary, KPIs
--glow-brandshadow del acento al 35%Halo de botones

14 presets pre-validados

En lugar de inventar colores, usá uno de los 14 presets disponibles en assets/css/presets/. Mirá la galería interactiva en presets.html.

✅ Hacer Usar uno de los 14 presets · cambiar de marca = cambiar 1 línea de <link>.
❌ No hacer Inventar colores hex sueltos · romper la armonía cromática del sistema.

06 · Componentes

Catálogo obligatorio

Todo curso DEBE usar solo los componentes del catálogo. Mirá showcase.html para verlos todos.

❌ Prohibido Inventar markup propio · cargar Bootstrap/Tailwind/Materialize · sobrescribir con !important.
✅ Si falta un componente Proponerlo para sumar al sistema · NO inventarlo solo para tu curso.
07 · Logo

Logo y placeholders

El template usa un placeholder SVG (assets/img/placeholders/logo.svg) con borde punteado y texto "LOGO" para que sea OBVIO que falta reemplazar.

Cuando el cliente entrega su logo, simplemente reemplazá ese archivo · el sidebar lo tomará automáticamente.

✅ Recomendado Logo en SVG · escala perfecta · se tinta con el color del preset si usa currentColor.
❌ Evitar Logos PNG/JPG menores a 200×200 · se pixelan en Retina.
08 · Voz

Voz y tono

  • Tuteo o "vos" consistente · elegir uno por curso.
  • Frases cortas · máx 25 palabras.
  • Voz activa · no pasiva.
  • Sin emojis en contenido educativo (sí en demos/promociones).
  • Sin MAYÚSCULAS para énfasis · usá <strong>.

10 · A11y

Accesibilidad

  • Contraste AA mínimo en todos los textos · verificar en las 3 versiones.
  • alt en todas las imágenes.
  • aria-label en botones de solo icono.
  • Navegación por teclado funcional (← → para prev/next).
  • Touch target mínimo 40×40 px.
11 · Cierre

Checklist pre-publicación

Antes de entregar el curso al cliente verificá:

  • El preset está definido (uno de los 14 o uno custom).
  • El logo placeholder fue reemplazado por el real del cliente.
  • course.js tiene todos los datos (menú, glosario, créditos, referencias).
  • Cada pantalla tiene su data-current correcto.
  • El contenido se ve bien en las 3 versiones (Híbrida / Clara / Oscura).
  • Funciona en mobile sin desbordes.
  • Los enlaces prev/next del nav funcionan en todas las pantallas.
  • El glosario y créditos se auto-renderizan correctamente.
  • No quedan textos placeholder ("Lorem ipsum", "Editar este texto").
  • Imágenes optimizadas (< 200KB cada una).
  • El curso completo carga en < 3 segundos en 3G.
